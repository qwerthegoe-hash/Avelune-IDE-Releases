# Avelune IDE — Windows releases

Download the latest Windows executable from [Releases](https://github.com/qwerthegoe-hash/Avelune-IDE-Releases/releases/latest).

This repository contains only release information. The application source code is not published here. GitHub's automatic “Source code” archives contain this README, not the application's source files.

The update manifest at https://avelune.stream/updates/stable.json is cryptographically signed and contains the release SHA-256 hash. The current portable EXE itself is not digitally code-signed. Windows may display a SmartScreen warning.

To run the portable version, download `Avelune-IDE-...-portable.exe` and open it. A Google account and a personal Gemini API key are needed for the full feature set.
